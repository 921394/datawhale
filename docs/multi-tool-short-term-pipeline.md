# 多工具短线策略流水线

本文把“小市值股票启动后持有 1-3 天”的研究拆成多个可替换环节。目标是先完成历史研究和模拟交易，不连接真实账户。

## 1. 工具分工

```text
AKShare 获取数据
    -> Qlib 研究历史特征和参数组合
    -> vn.py 图形化回测、调参和查看收益曲线
    -> gupiao 每日扫描当前候选
    -> vn.py 或其他模拟盘验证成交、滑点和涨跌停影响
```

| 环节 | 工具 | 主要产物 |
| --- | --- | --- |
| 数据获取 | AKShare | 本地 A 股日线 CSV、股票清单和下载清单 |
| 历史研究 | Qlib | 特征统计、样本内/样本外结果和参数候选 |
| 图形化回测 | vn.py `cta_backtester` | 回测指标、交易记录、参数优化结果和收益曲线 |
| 每日扫描 | gupiao | 满足当前参数的股票列表和个股报告 |
| 模拟交易 | vn.py 或券商仿真环境 | 委托、成交、持仓、滑点和异常记录 |

vn.py 的 `cta_backtester` 支持图形界面回测、参数优化、绩效指标、委托记录和优化结果导出，适合做策略参数的可视化调整。[官方回测文档](https://github.com/vnpy/vnpy/blob/master/docs/community/app/cta_backtester.md)

## 2. 研究字段

第一版使用以下字段定义“启动前状态”：

- 启动前 3 日、5 日收益率；
- 5 日均线与 20 日均线的相对位置；
- 成交量相对过去窗口的放大程度；
- 换手率；
- 流通市值；
- 行业、概念和热点板块标签；
- 未来 1 日、2 日、3 日收益率和是否达到预设收益阈值。

其中日线接口通常可以提供价格、成交量、成交额和换手率，但历史流通市值不能用当前市值回填。当前市值只能用于当日筛选；历史回测必须使用当时可获得的股本和价格数据，否则会引入未来数据泄漏。行业、概念和新闻标签也要按信息发布日期对齐。

## 3. 数据下载

下载脚本位于 [`scripts/download_akshare_a_share.py`](../scripts/download_akshare_a_share.py)。默认按股票分别保存 CSV，支持失败重试和断点续传，数据目录不提交到 GitHub：

```bash
cd /home/opc/trader/datawhale
python scripts/download_akshare_a_share.py \
  --start-date 20210101 \
  --end-date 20260825 \
  --adjust qfq \
  --workers 4 \
  --output-dir /home/opc/trader/market_data/akshare/a_share_daily
```

首次运行会通过 `AKShare` 获取沪深京 A 股代码列表，然后逐只请求历史日线。`--workers` 可以并发下载，但并发过高可能触发数据源限流；网络中断时可以重复执行同一条命令，已存在且非空的股票文件会跳过。建议先用 `--limit 20` 做连通性和字段检查，再开始全市场下载。

原始下载文件使用统一字段：

```text
code,provider,date,open,high,low,close,volume,amount,float_shares,turnover_pct
```

`qfq` 适合连续收益和技术指标研究；如需检查除权除息影响，应另外保存 `raw` 或 `hfq` 数据，不能在同一回测中混用。脚本默认优先使用 AKShare 的新浪日线接口，并在失败时尝试东方财富接口。实际运行过程见[流水线运行记录](pipeline-run-log.md)。

## 4. 历史参数研究

用 Qlib 或 pandas 生成特征和标签：

```text
特征日 T：只能使用 T 收盘时已经知道的数据
入场日：约定为 T+1 开盘或 T+1 可成交价格
标签：T+1、T+2、T+3 的收益和最大不利波动
```

研究时至少要做：

1. 按时间切分训练、验证和样本外区间；
2. 分别统计上涨概率、平均收益、中位数收益和最大回撤；
3. 加入手续费、印花税、滑点、涨跌停和无法成交的情况；
4. 检查不同年份、行业和市值分组是否仍然有效；
5. 记录每次参数搜索，避免只报告最优组合。

“上涨概率高”不等于可盈利。最终应按成本后的期望收益、回撤、成交容量和样本外稳定性筛选参数。

## 5. 回测、扫描和模拟

研究得到候选条件后，将最小策略实现为 vn.py 策略类，在 `cta_backtester` 中调整参数并查看收益曲线。gupiao 只负责把同一套条件应用于最新交易日的全市场数据，输出候选股票，不负责证明策略有效。

进入模拟交易前，必须单独记录：

- T+1 规则和可卖出时间；
- 涨停买不到、跌停卖不出的订单状态；
- 停牌、缺失行情和复牌跳空；
- 手续费、印花税、滑点和最小交易单位；
- 信号时间、下单时间、成交时间和使用的数据版本。

模拟交易连续运行一段时间并完成样本外验证后，再评估是否需要券商接口。本文不构成投资建议，也不承诺收益。
