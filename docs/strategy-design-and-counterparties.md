# 策略设计思想与收益来源

策略不能只按“均线、MACD、机器学习”分类。更重要的问题是：**它为什么可能有效，承担了什么风险，收益由谁或什么机制支付。**

## 1. 先区分收益类型

```text
股票现货：企业盈利/分红 + 市场风险溢价 + 相对选股收益 - 成本
期货期权：一方收益通常对应另一方损失 - 成本
做市交易：买卖价差 - 库存风险 - 逆向选择风险
执行策略：基准成交成本 - 实际成交成本
```

因此，“赚谁的钱”不能总是理解为从某个散户账户直接拿钱。收益可能来自企业现金流、风险补偿、行为偏差、被迫交易、流动性服务或执行差异。

## 2. 按设计思想分类

### A. 市场暴露和资产配置

**设计假设：**市场或某类资产长期提供正的风险溢价。

**典型策略：**指数、ETF、股债配置、风险平价、指数增强。

**交易动作：**持有市场或风格暴露，按规则再平衡。

**收益来源：**企业盈利、分红、经济增长，或投资者承担市场风险得到的补偿。

**交易对手/支付者：**不是固定的某类人，主要是经济活动产生的现金流和愿意转移市场风险的投资者。

**A 股适配：**高。适合从 ETF、指数和简单指数增强开始。

### B. 动量和趋势

**设计假设：**价格信息不会瞬间被所有参与者吸收，强势资产可能在一段时间内继续强势。

**典型策略：**过去 3～12 个月收益排名、均线趋势、突破、时间序列动量。

**交易动作：**买入相对强或自身趋势为正的资产，趋势反转后退出。

**收益来源：**信息反应滞后、投资者追涨、资金持续流入和规则化跟随交易。

**交易对手/支付者：**较慢反应的交易者、追涨后接盘者、趋势反转前仍持有的交易者；但收益并非每笔都来自某个具体对手。

Jegadeesh 和 Titman 的经典研究考察了买入过去赢家、卖出过去输家的中期动量策略。[原始论文](https://onlinelibrary.wiley.com/doi/10.1111/j.1540-6261.1993.tb04702.x)；时间序列动量的跨资产研究见 [AQR 研究](https://www.aqr.com/insights/research/journal-article/time-series-momentum)。

**主要风险：**震荡行情反复止损，趋势突然反转，换手和滑点过高。

**A 股适配：**中高。A 股不能简单照搬多空版本，通常先做多头排名或 ETF 趋势。

### C. 反转和均值回归

**设计假设：**价格可能因为情绪、流动性冲击或被迫交易而暂时偏离，之后部分回归。

**典型策略：**超跌反弹、短期反转、布林带回归、配对价差回归。

**交易动作：**买入短期跌幅异常的资产，或卖出/回避短期过热的资产。

**收益来源：**恐慌卖出、流动性冲击、过度反应和交易压力消退。

**交易对手/支付者：**被迫卖出者、恐慌交易者和急于成交的流动性需求者。

长期极端赢家和输家的反向表现被 De Bondt 与 Thaler 研究过。[原始研究](https://www.aeaweb.org/articles?id=10.1257/jep.3.1.189)

**主要风险：**价格下跌可能是基本面永久恶化，而不是暂时偏离；容易出现连续补仓和越跌越买。

**A 股适配：**中。必须加入停牌、跌停、退市和基本面过滤。

### D. 价值、质量、规模和其他因子

**设计假设：**某些公司的估值、盈利质量、规模或投资特征与未来收益存在长期关系。

**典型策略：**低估值、高质量、小市值、低波动、盈利成长、多因子模型。

**交易动作：**计算因子分数，按分数构建分组或组合，定期调仓。

**收益来源：**可能是风险补偿，也可能是投资者行为偏差和资金约束；不能简单归因于“预测能力”。

**交易对手/支付者：**不愿持有困难资产、需要流动性、受风险约束或存在行为偏差的投资者；也可能只是承担了更高风险后的补偿。

Fama 和 French 的资产定价研究是理解因子和风险溢价的基础入口。[资产定价综述](https://www.aeaweb.org/articles?id=10.1257/0895330042162430)

**主要风险：**因子拥挤、长期失效、财务数据滞后、股票池幸存者偏差和行业集中。

**A 股适配：**高，但必须处理财报发布时间、停牌、退市和行业中性问题。

### E. 相对价值和统计套利

**设计假设：**经济关系相近的资产出现暂时性错价，价格最终可能收敛。

**典型策略：**配对交易、行业内相对强弱、ETF 与成分股价差、跨市场套利。

**交易动作：**买入相对便宜的一边，卖出或回避相对昂贵的一边。

**收益来源：**市场分割、资金压力、交易限制、不同参与者反应速度不同。

**交易对手/支付者：**被迫交易、跨市场受限、资金成本更高或反应更慢的参与者。

Gatev、Goetzmann 和 Rouwenhorst 的配对交易研究将这种方法定义为相对价值套利，并讨论了暂时性错价和微观结构影响。[NBER 原始研究](https://www.nber.org/papers/w7032)

**主要风险：**价差可能不收敛，相关关系可能永久断裂；A 股做空限制会破坏理论上的中性结构。

**A 股适配：**中低到中，取决于标的、账户权限和执行工具。

### F. 事件驱动和被动资金流

**设计假设：**财报、指数调仓、分红、重组等事件会带来可预测的交易需求或价格重新定价。

**典型策略：**指数成分调整、财报公告、分红除权、停牌复牌、可转债转股。

**交易动作：**在事件发生前后按规则持仓或退出。

**收益来源：**被动基金的强制调仓、信息处理差异、事件不确定性溢价。

**交易对手/支付者：**必须按指数或制度规则交易的机构、事件判断错误者，以及为流动性和不确定性付费的投资者。

**主要风险：**事件时间泄漏、公告内容变化、停牌无法成交、规则调整和事件结果跳变。

**A 股适配：**中。数据和事件时间戳质量是核心难点。

### G. 做市和流动性提供

**设计假设：**愿意提供即时成交的人，可以获得买卖价差作为服务费和风险补偿。

**典型策略：**双边报价、库存管理、价差动态调整。

**收益来源：**买卖价差、订单处理费和流动性风险溢价。

**交易对手/支付者：**主动吃单、急于成交、需要即时流动性的交易者。

市场微观结构研究通常将价差拆分为订单处理成本、库存风险和逆向选择风险。[价差与库存风险研究](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=336242)

**主要风险：**被更有信息的交易者“挑中”、库存单边积累、突发行情和技术故障。

**A 股适配：**个人不适合作为入门方向，通常需要专业权限、系统和资金规模。

### H. 期权、波动率和保险

**设计假设：**投资者愿意为保护、杠杆和尾部收益支付权利金；隐含波动率与未来实际波动可能存在差异。

**典型策略：**卖出波动率、波动率曲面套利、Delta 对冲、保护性期权。

**收益来源：**保险费、波动率风险溢价和不同期限/执行价之间的定价差异。

**交易对手/支付者：**购买保险、保护组合或追求凸性收益的期权买方。

研究常将期权卖方收益与波动率风险溢价联系起来，但卖方承担尾部风险，不能理解成稳定收租。[波动率风险溢价研究](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=3739933)

**主要风险：**极端行情、跳空、保证金、流动性和模型误差。

**A 股适配：**复杂且权限受限，不适合第一阶段。

### I. 执行和数据优势

**设计假设：**即使策略信号相同，更好的数据、延迟、拆单和成交管理也能减少成本。

**典型策略：**VWAP/TWAP、成交量预测、订单拆分、低冲击执行、另类数据处理。

**收益来源：**少支付滑点、少承受市场冲击、更快处理公开信息。

**交易对手/支付者：**不一定存在固定输家；收益更多体现为相对其他交易者少付成本或更早完成信息反应。

**主要风险：**技术故障、数据质量、容量和市场环境变化。

**A 股适配：**研究上可做，生产化通常是机构级工程问题。

## 3. 策略设计模板

任何策略都应该先写清楚下面八个问题：

1. 市场假设是什么？
2. 哪些数据在交易时点已经可见？
3. 信号如何计算？
4. 买入和卖出时点是什么？
5. 仓位如何分配？
6. 手续费、滑点和无法成交如何处理？
7. 最坏情况下会亏多少？
8. 如何做样本外和压力测试？

如果只能说“指标金叉就买”，说明只有信号，还没有完整策略。

## 4. A 股的学习顺序

```text
指数/ETF 与 Beta
    -> 指数增强
    -> 因子选股
    -> 动量与均值回归
    -> 组合与风险管理
    -> 事件驱动
    -> 可转债/期权
```

先研究收益来源，再研究指标和代码。论坛里的收益截图可以作为线索，但不能代替数据、成本、样本外和可执行性验证。
