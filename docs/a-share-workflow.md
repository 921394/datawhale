# A 股量化完整工作流

本文回答三个问题：整体流程是什么、现成策略和框架怎么用、什么时候可以开始自己做策略。

## 1. 总体流程

```text
明确市场与目标
    -> 准备和检查数据
    -> 使用现成策略跑通回测
    -> 理解并修改策略
    -> 样本外验证
    -> 仿真交易
    -> 接入券商接口
    -> 实盘监控与风控
```

| 阶段 | 完成方式 | 交付物 |
| --- | --- | --- |
| 明确目标 | 限定 A 股股票/ETF、日线/分钟线、单标的/多标的 | 一页策略需求 |
| 数据准备 | 获取合规行情，检查时间、复权、停牌、缺失值和重复记录 | 数据质量报告 |
| 现成策略 | 先运行双均线、动量或再平衡策略，不改参数 | 第一个可运行回测 |
| 诚实回测 | 加手续费、滑点、交易单位、资金限制和成交时点 | 回测报告 |
| 策略验证 | 做样本外、走步验证、参数敏感性和基准对比 | 验证报告 |
| 仿真交易 | 观察订单、成交、持仓、断线恢复和重复下单 | 仿真记录 |
| 实盘接入 | 根据券商支持的接口选择 QMT、PTrade、XTP、TORA 或 Gateway | 实盘程序 |
| 运维风控 | 配置限仓、最大亏损、告警、日志和人工停止 | 风控手册 |

A 股回测必须考虑交易时段、申报数量、回转交易、停牌和复权等规则，具体以交易所最新规则为准。[上海证券交易所交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)

实盘程序化交易还涉及报告和监控要求，接入券商前应确认账户权限和合规流程。[证监会证券市场程序化交易管理规定](https://www.csrc.gov.cn/csrc/c100028/c7480577/content.shtml)

## 2. 现成策略怎么用

现成策略的作用是理解完整流程，不是直接获得收益。

推荐顺序：

1. 原样运行，确认代码、数据和结果可复现。
2. 看懂指标、信号、持仓、成交和退出条件。
3. 检查是否使用了未来数据。
4. 加入 A 股手续费、滑点和交易限制。
5. 与买入并持有基准比较。
6. 只修改一个参数，观察结果变化。
7. 用没有参与调参的数据做样本外验证。

适合入门的策略类型：

- 双均线趋势策略；
- 动量排名策略；
- 定期再平衡策略；
- 均值回归策略；
- ETF 轮动策略；
- 基于价值、质量或波动率的因子策略。

这些策略是学习样例，不代表具有投资价值。使用 GitHub 代码前要检查许可证、数据假设和是否适用于 A 股。

## 3. 框架怎么选

### 本地研究

先用：

```text
Python + pandas + VectorBT
```

`pandas` 负责数据处理，VectorBT 负责快速测试多个参数和标的。[VectorBT 文档](https://vectorbt.dev/)

### 复杂回测

当策略需要逐笔订单、事件驱动和更细的成交模拟，再考虑 Backtrader、LEAN 或 vn.py 的回测模块。不要一开始同时学习多个框架。

### A 股实盘

先问券商：是否支持程序化交易、支持哪种接口、是否有仿真环境、是否需要报备、是否提供行情和交易接口，以及断线和成交回报如何处理。

如果券商接口与 vn.py 兼容，可以使用 vn.py；否则使用券商提供的 QMT、PTrade、XTP、TORA 等接口。vn.py 官方文档列出了部分股票和期权 Gateway，但账号和权限仍需向券商申请。[vn.py Gateway 文档](https://www.vnpy.com/docs/cn/community/info/gateway.html)

Qlib 更适合后续因子研究和机器学习，不建议作为第一个回测工具。[Qlib GitHub](https://github.com/microsoft/qlib)

## 4. 什么时候开始自己做策略

当你能做到以下事情，就可以从模仿进入自研：

- 解释每个数据字段的含义；
- 说明信号使用哪个时间点的数据；
- 说明订单什么时候成交；
- 计算手续费、滑点和最大回撤；
- 找出未来数据泄漏；
- 完成样本外验证；
- 重现以前的回测结果。

自研策略的模板是：

```text
市场假设
    -> 可观测数据
    -> 指标或因子
    -> 买卖信号
    -> 仓位大小
    -> 交易执行
    -> 风险控制
    -> 回测与验证
```

例如：

```text
假设：强势股票短期可能继续强势
数据：过去 20 日收益率
信号：在股票池中按收益率排序
仓位：每只股票等权
执行：下一个交易日开盘成交
风险：单只股票不超过组合的 10%
验证：样本外回测并与基准比较
```

只有“均线金叉买入”还不算完整策略，因为缺少成交、仓位、退出和风险规则。

## 5. AI 在流程中的位置

AI 可以帮助：

- 解释金融和统计概念；
- 把策略想法转换成代码；
- 生成数据检查脚本；
- 分析 Python 报错；
- 审查未来数据泄漏；
- 生成测试数据；
- 比较回测结果；
- 检查重复下单、断线恢复和密钥暴露。

可以直接使用：

```text
我是 A 股量化初学者，请用 Python 和 pandas 写一个最简单的双均线回测。

要求：
1. 明确说明信号使用哪个时点的数据；
2. 不允许未来数据泄漏；
3. 包含手续费、滑点、现金余额和持仓数量；
4. 输出交易明细、每日净值、总收益、最大回撤和买入并持有基准；
5. 先生成 10 行人工测试数据，验证手续费、滑点和仓位变化；
6. 逐行解释关键代码；
7. 最后列出这段回测仍然没有模拟的 A 股规则。
```

AI 生成代码后，必须自己确认时间对齐、成交时点、交易成本、异常处理和数据泄漏。代码能运行不等于回测正确。

## 6. 推荐进阶顺序

```text
现成策略跑通
    -> 修改参数
    -> 修改一个规则
    -> 加入 A 股交易约束
    -> 做样本外验证
    -> 提出自己的市场假设
    -> 自己设计策略
    -> 仿真交易
```

不要直接让 AI 生成“自动赚钱策略”或完整交易平台；先解决一个能验证的小问题。
