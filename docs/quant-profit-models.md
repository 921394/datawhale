# 量化赚钱的方式

量化不只有“预测明天涨跌”。更准确地说，量化是在可验证的假设基础上，寻找长期正期望的收益来源，再通过组合、执行和风控把它稳定实现。

## 1. 收益的基本拆解

```text
总收益
= 市场 Beta
+ 风格/因子收益
+ 选股或择时 Alpha
+ 执行收益
+ 分红/利息
- 手续费
- 滑点
- 风险损失
```

### Beta

买入指数或 ETF，赚取市场整体上涨。例如持有沪深 300 ETF，主要获得的是市场 Beta，而不是主动选股能力。

### Alpha

如果市场上涨 10%，你的组合上涨 15%，超过基准的部分才可能是选股或策略 Alpha。但这部分也可能来自更高的小盘股、成长股或高波动风险，必须继续拆解。

## 2. 主要收益方式

| 方式 | 核心思想 | A 股个人可行性 |
| --- | --- | --- |
| 市场 Beta | 买入指数或 ETF，赚市场整体收益 | 高 |
| 指数增强 | 跟踪指数，同时主动选择更强股票 | 高 |
| 因子投资 | 按估值、质量、动量、波动率等特征选股 | 高 |
| 动量/趋势 | 买入近期较强的资产，假设强势延续 | 高 |
| 均值回归 | 买入短期偏离较大的资产，等待回归 | 中 |
| 事件驱动 | 利用财报、分红、指数调仓、重组等事件 | 中 |
| 统计套利 | 利用相关资产之间的异常价差 | 受做空和权限限制 |
| 可转债套利 | 利用转债、正股和转股价值之间的关系 | 中高 |
| ETF 套利 | 利用 ETF、成分股和申赎机制的价差 | 资金和权限要求高 |
| 期权波动率 | 交易隐含波动率与实际波动率的差异 | 复杂且有权限要求 |
| 资产配置 | 在股票、债券、黄金、现金之间分配风险 | 高 |
| 执行优化 | 通过拆单和择时降低滑点及冲击成本 | 机构为主 |
| 做市 | 同时提供买卖报价，赚取买卖价差 | 个人不适合作为入门 |

## 3. 具体例子

### 因子选股

```text
给股票打分
    -> 选择排名靠前的一组
    -> 控制单只股票仓位
    -> 定期调仓
    -> 与指数基准比较
```

评分可以来自估值、盈利质量、动量、波动率或多个因子组合。它不要求每只股票都上涨，只要求组合长期比基准更强。

### 统计套利

```text
两个长期相关的资产出现异常价差
    -> 买入相对便宜的
    -> 卖出相对昂贵的
    -> 等待价差回归
```

A 股个人投资者做空能力有限，理论上的多空策略经常只能改造成多头选强策略。

### 事件驱动

事件驱动可以研究财报、分红除权、指数成分调整、停牌复牌和可转债转股等事件。难点是事件数据的发布时间、交易时点和规则处理，必须防止未来数据泄漏。

### 执行优化

同样买入一笔大订单，成交价格更好就能产生收益：

```text
别人平均买贵 0.5%
你平均只买贵 0.1%
节省的 0.4% 就是执行收益
```

执行优化涉及拆单、成交量预测、订单排队、冲击成本和撤单管理，通常是机构级进阶方向。

## 4. 不通过交易赚钱

量化能力也可以转化为非交易收入：

- 开发回测工具；
- 提供数据清洗和数据服务；
- 开发选股或分析软件；
- 提供量化系统外包；
- 提供研究、培训或技术服务。

这类收入来自软件、数据或服务，不等于策略本身获得了市场收益，也需要单独考虑产品、客户和合规问题。

## 5. 为什么回测赚钱，实盘却可能亏

- **过拟合：**策略只记住了历史噪声；
- **数据泄漏：**使用了当时不可能知道的信息；
- **成本遗漏：**没有模拟手续费、印花税、滑点和换手；
- **市场变化：**策略只在某个牛市或震荡阶段有效；
- **容量不足：**小资金有效，大资金会冲击价格；
- **执行失败：**涨跌停、停牌、断线或成交回报异常。

因此不能只看总收益，还要看最大回撤、换手率、成本敏感性、样本外结果和不同市场阶段的表现。

## 6. A 股学习优先级

```text
指数和 ETF
    -> 指数增强
    -> 简单因子选股
    -> 动量和均值回归
    -> 组合管理
    -> 事件驱动
    -> 可转债或期权
```

暂时不要从高频、做市、复杂套利或深度学习开始。先回答清楚：

1. 策略利用了什么规律？
2. 收益来自 Beta、因子、Alpha 还是风险补偿？
3. 扣除成本后还剩多少？
4. 换一段数据后是否仍然成立？
5. 最坏情况下会亏多少？

量化不是预测机器，而是把一个可能存在的统计优势转化成明确的选股、仓位、执行和风控规则，并长期重复执行。
